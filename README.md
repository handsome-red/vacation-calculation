# Калькулятор отпусков

> Создать инструмент для кадровика, позволяющий:  
> 1. Рассчитывать количество дней ежегодного оплачиваемого отпуска за отработанный период.
> 2. Рассчитывать остаток неиспользованных жней на текущую дату.
> 3. Сотруднику и отделу кадров на электронную почту поступали уведомления о предстоящем отпуске за 28 календарных дней в соответствии со служебной запиской.  

Сотрудники делятся на группы:  
1. Государственные служащие (79-ФЗ) // Категория должностей ст.9 №79-ФЗ
2. Прочий персонал (ТК РФ) // Начальник гаража, Водитель автомобиля, Сторож(вахтер), Заведующий хозяйством, Заведующий складом, Документовед, Делопроизводитель, Подсобный рабочий, Инженер-программист
